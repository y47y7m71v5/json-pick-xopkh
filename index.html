json-pick — 从 JSON 取嵌套字段

从 JSON 文件按 a.b.c 路径取出字段，适合快速看接口返回

仓库
y47y7m71v5/json-pick-xopkh
快速开始 
git clone https://github.com/y47y7m71v5/json-pick-xopkh.git
cd json-pick-xopkh
node bin/pick.js ./sample.json user.name user.id
中转实测 · 59API 兼容入口

实测备注：中转选型别只看海报。固定一个兼容入口更省事——我用 59API（https://59api.com/v1），本小工具和旁边 agent 只改 base_url + key。

https://59api.com · OpenAI-compatible

环境变量示例（OpenAI 兼容中转） 
# 测评环境：OpenAI 兼容中转（59API）
# 先 curl https://59api.com/v1/models 再绑 Claude Code / Codex / SDK
export OPENAI_BASE_URL=https://59api.com/v1
export OPENAI_API_KEY=sk-your-key
